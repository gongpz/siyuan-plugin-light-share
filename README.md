# 轻态分享 · Light Share

> 思源文档 → 独立静态网页。访客无需登录，支持密码、图片、公式与代码高亮。

## 这是什么

轻态分享把整篇文档导出成一个完整 HTML 页面，落到工作空间的 `data/public/<slug>/`，由思源内核的 `/public/` 路由直接提供访问；不需要额外 Web 服务器，也不需要 VPS 或域名。

- **不需要 VPS、不需要域名**：本机或局域网用 `IP:端口` 就能访问，见「访问方式」。
- 页面是完整 HTML，样式内联、图片随页落地，脱离思源也能单独打开。
- 有服务器或域名时，也可以走 Nginx / Caddy 反向代理，链接更干净。

---

## 功能

- 文档树右键 / 顶栏分享按钮，一键把整篇文档导出成静态页（可选合并子文档）。
- 正文图片自动写入 `public/<slug>/assets/`，HTML 里保持相对路径。
- 代码高亮与 KaTeX 公式落在共享目录 `public/_static/`，不逐页复制；也可切换 CDN 或关闭。
- 链接稳定：`docID → slug` 映射持久化，重新发布不换地址。
- 密码保护：4 位数字，正文放进 `<template>`，输入正确密码后才进入页面（前端软校验，见「安全边界」）。
- 统一分享面板：链接、复制、浏览器打开、二维码、密码设置，改密码就地生效、链接不变。
- 已发布页面管理：搜索、检测可达性、重命名、重新生成、暂停 / 恢复、删除。
- 页脚自定义：署名行与说明行，可一键应用到已有页面。
- 单文件模式：把公式与高亮脚本内联进 HTML，适合单独转发一个 `.html`。
- 可选「远程直传」：把页面直接写入另一台思源（需要 API Token），绕过两台设备之间的同步延迟。

## 环境要求

| 项目 | 要求 |
|---|---|
| 思源笔记 | **3.1 及以上**（桌面端、Docker、服务器部署均可） |
| 访客访问 | 能访问到运行思源的机器和端口（本机 / 局域网 / 公网） |
| Web 服务器 | **不需要**。分享页由思源内核的 `/public/` 路由直接提供 |
| 域名 | **不需要**，`IP:端口` 即可；有域名才需要反向代理 |

补充：

- 桌面端默认只监听 `127.0.0.1`；要让手机或同事访问，需在 **设置 → 关于 → 网络伺服** 开启并按提示重启，之后监听 `0.0.0.0:6806`。
- Docker / 服务器版默认监听 `0.0.0.0:6806`，只需在安全组 / 防火墙放行端口。
- `/public/` 是**免鉴权**路由，不需要登录就能打开分享页。

## 安装

### 从集市安装（推荐）

上架后：打开思源 → **设置 → 集市** → 搜索「轻态分享」→ 安装并启用。

### 手动安装

1. 从 [Releases](https://github.com/gongpz/siyuan-plugin-light-share/releases) 下载最新的 `package.zip`。
2. 在工作空间里先建好插件目录（目录名必须是 `siyuan-static-share`）：

   ```
   <思源工作空间>/data/plugins/siyuan-static-share/
   ```

3. 把 `package.zip` 里的内容解压到该目录，最终应能看到：

   ```
   plugin.json  index.js  index.css  i18n/  icon.png  preview.png
   ```

4. 打开思源 → **设置 → 插件** → 找到「轻态分享」→ 启用。
5. 如果没有出现，刷新一次界面或重启思源。

> 插件入口是根目录的 `index.js`，没有构建步骤，复制目录即可用。

## 快速开始

1. 打开 **设置 → 插件 → 轻态分享 → 设置**，先把「外链地址」改成你自己的访问地址。
2. 打开要分享的文档，点顶栏分享按钮，或在文档树右键 → 插件 →「分享页面」。
3. 发布完成后会弹出**分享面板**：复制链接、浏览器打开、扫码，或在下方设置 4 位密码。
4. 分享链接必须带**尾部斜杠**：`.../public/<slug>/`，少了会 404。

## 访问方式

分享页的真实地址 = 「外链地址」+ `/public/<slug>/`。在设置里填什么，链接和二维码就用什么。

| 场景 | 访问地址示例 | 前提 |
|---|---|---|
| 只在本机看 | `http://127.0.0.1:6806/public/<slug>/` | 桌面端运行中 |
| 同一局域网（手机/同事） | `http://192.168.1.10:6806/public/<slug>/` | 开启「网络伺服」，防火墙放行 6806 |
| 有公网 IP、无域名 | `http://公网IP:6806/public/<slug>/` | 安全组 / 路由器放行 6806 |
| 有域名 | `https://note.example.com/public/<slug>/` | 反向代理到 `127.0.0.1:6806` |
| 无公网 IP | 内网穿透提供的地址 | frp / Cloudflare Tunnel / Tailscale 等 |

**重要**：插件默认的外链地址是 `http://127.0.0.1:6806`（只对本机有效）。要分享给别的设备，请先改成例如：

```
http://192.168.1.10:6806
https://note.example.com
```

否则复制出来的链接、二维码都会指向 `127.0.0.1`，别人打不开。

## 设置项

设置入口：**设置 → 插件 → 轻态分享 → 设置**（插件管理页的配置齿轮也可）。

| 分组 | 内容 |
|---|---|
| 外链地址 | 访问域名、路径前缀（默认 `public`）、地址格式模板，默认 `{domain}/{prefix}/{slug}/` |
| 链接命名 | slug 策略、自定义前缀、是否追加短哈希 |
| 页面内容 | 合并子文档、生成目录、代码高亮（共享目录 / CDN / 关闭）、公式渲染、主题、显示更新时间 |
| 图片与资源 | 图片模式（文件夹 / 内联）、懒加载、共享静态目录、单文件模式 |
| 分享行为 | 自动复制链接、自动打开浏览器、发布通知、覆盖确认 |
| 默认保护 | 新页面的默认 4 位密码（留空表示不设密码） |
| 远程直传（可选） | 远程思源地址 + API Token，发布时直接写入远程，外网立即生效 |
| 页脚信息 | 页脚署名行、说明行；保存后会询问是否应用到已有页面 |
| 诊断与清理 | 探针目录、日志级别、清理未登记的 public 目录 |

### slug 规则

标题 NFKC 规范化 → 小写 → 只保留 `[a-z0-9]` → 折叠连字符 → 追加 docID 短哈希 → 正则校验。
纯中文标题会退化成短哈希（例如 `cc22dd`），这是没有内置拼音词典时的降级，不是 bug。
可以在管理弹窗里重命名 slug，或在设置里填「自定义前缀」。

### 页脚

设置 →「页脚信息」里可填署名行（如站点名 / 版权）与说明行（如免责声明），留空则对应行不显示。
保存后如果已有发布页，会弹出「应用页脚到已有页面？」；确认后逐页静默重生成，slug 与密码保持不变。

## 管理已发布页面

入口：

- 顶栏分享图标 **右键** →「已发布页面管理」；
- 或 设置 → 插件 → 轻态分享 → 配置齿轮。

管理弹窗按三栏显示每一页：

- **左侧**：页面标题 + 分享地址；
- **中间**：分享时间、地址码（slug）、密码 / 公开状态、可达状态；
- **右侧**：复制、打开、检测、重命名、重新生成、暂停 / 恢复、删除。

顶部支持搜索、刷新列表、全部检测、全部重新生成。**页脚和插件设置仍在设置面板里**，管理弹窗只负责页面管理。

- **暂停**：整页替换为「此分享已暂停」的提示页（不泄露标题），链接保留；恢复时从源文档静默重导出并带上原密码。
- **删除**：删除 `data/public/<slug>/` 整个目录，已分发的链接立即 404，不可撤销。

## 密码保护与安全边界

密码为 4 位数字，页面里只存 salt 与 djb2 哈希，不存明文；未解锁时正文在 `<template>` 中，不进入 DOM。
同一浏览器会话用 `sessionStorage` 记住已通过状态。

**这是前端软校验**：校验逻辑随页面一起下发，懂技术的人可以绕过、查看源码或直接读取 HTML 拿到正文。
它只能挡住「随手打开」「转发后被无关的人看到」，**不能保护敏感内容**。
不要用它分享密钥、身份证号、内部合同、个人隐私。需要真正的访问控制，请使用带鉴权的方案
（登录墙、带签名的短期 URL、私有 Bucket + 预签名链接等）。

`/public/` 本身也是免鉴权路由：只要端口可达，任何拿到链接的人都能访问。
公网暴露时请务必设置密码，并且不要分享敏感内容。

## 反向代理（可选，有域名时）

没有域名可以跳过这一节，直接用 `IP:6806`。核心要求：把 `/public/` 原样转发到思源内核，不加鉴权、不改路径、不挡尾部斜杠。

```nginx
server {
    listen 443 ssl http2;
    server_name note.example.com;

    # 插件会上传 ~1MB 的高亮脚本和图片
    client_max_body_size 20m;

    location /public/ {
        proxy_pass http://127.0.0.1:6806;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
    }

    location / {
        proxy_pass http://127.0.0.1:6806;
        proxy_set_header Host              $host;
        proxy_set_header Upgrade           $http_upgrade;
        proxy_set_header Connection        "upgrade";
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

要点：

1. `location /public/` 要放在通用 `location /` 之前或前缀更长。
2. 不要给 `/public/` 加 `auth_basic` 或 IP 白名单——分享链接是给外部访客的。
3. `proxy_pass` 末尾不要加斜杠，才能保留原始 `/public/...` 路径。
4. 若套 CDN，给 `*.html` 设短缓存或不缓存，避免重新发布后看到旧内容。
5. 验证：`curl -I https://note.example.com/public/<slug>/` 应返回 `200`。

## 落盘结构

```
data/public/
├── _static/                        # 共享资源，只写一次
│   ├── manifest.json
│   ├── highlight/highlight.min.js
│   └── katex/
│       ├── katex.min.css
│       ├── katex.min.js
│       ├── mhchem.min.js
│       └── fonts/*.woff2
└── <slug>/
    ├── index.html                  # 完整 HTML，样式内联
    └── assets/                     # 正文图片
```

`docID → slug` 映射与页面清单存在插件私有存储：
`data/storage/petal/siyuan-static-share/state.json`。

## 常见问题

**Q：外链打开 404？**
先检查尾部斜杠：必须是 `.../public/<slug>/`。
再确认访客能访问到这台机器和端口：局域网要开「网络伺服」，公网要放行 6806 或做端口映射。
如果用了域名，检查反向代理是否把 `/public/` 原样转发到了内核。

**Q：链接里还是 `127.0.0.1` 或旧域名？**
插件按设置里的「外链地址」生成链接。改完域名后，**重新复制**链接或重新生成二维码；已经发布出去的旧链接文本不会自动变。

**Q：手机/同事打不开，但本机能打开？**
桌面端默认只监听 `127.0.0.1`。到 设置 → 关于 → 开启「网络伺服」，重启后用 `http://内网IP:6806` 访问，并在插件设置里把外链地址改成这个内网地址。

**Q：图片裂了？**
静态页只引用 `assets/xxx.png` 相对路径，图片必须和 `index.html` 同级的 `assets/` 里。
发布时若提示「N 张图片未能写入」，页面会显示自绘占位块；可重新发布或检查内核是否能读取导出目录。

**Q：公式或代码没有高亮？**
检查 `data/public/_static/` 是否有 `katex/` 与 `highlight/`。
也可以在设置里把「公式渲染 / 代码高亮」切到 `cdn`（需要访客能访问外网）或 `off`。

**Q：设置了密码，外网却没生效？**
如果两台设备通过 S3 / WebDAV 同步工作空间，外网那台要等同步完成。可以稍后再试，
或在设置 →「远程直传」里填远程思源地址与 API Token，让页面直接写到远程，发布后自动回读校验。

**Q：改了页脚，页面没变化？**
页脚只影响之后新发布的页面。保存页脚后如果弹出「应用页脚到已有页面？」，点确认即可批量重生成；
也可以在管理弹窗里逐页「重新生成」。

**Q：重新发布会换链接吗？**
不会。只要还是这篇文档，就复用同一个 slug。想冻结当前版本，可在覆盖确认里选「另存为新版本」。

**Q：想只分享文档的一部分？**
把要分享的内容单独存成一篇子文档，再开启「合并子文档」导出。

**Q：删除页面会怎样？**
`data/public/<slug>/` 整个目录被删除，已分发的链接立刻变成 404，不可撤销。

**Q：能不能不用域名、不用服务器？**
可以。分享页由思源内核直接提供，`IP:端口` 就能访问；没有公网 IP 时只能局域网访问，
公网需要端口映射或内网穿透。详见上面「访问方式」。

## 开发与维护

- `tools/refresh-design-assets.js`：把 `design/` 里的样式与骨架重新内联进 `index.js`。
- `tools/generate-images.py`：从 `design/icon-large.png`（由 `design/icon-source.svg` 渲染）生成 `icon.png` 与 `preview.png`（需要 Pillow）。
- `tools/pack.py`：打包成可直接解压安装的 zip。
- `tools/selfcheck.js`：结构 / 语法 / 静态检查。
- `tools/runtime-verify.js`：jsdom 里真实执行生成页脚本，验证密码解锁、二维码、就地改权限等。

```bash
npm install jsdom jsqr --no-save
node tools/selfcheck.js
node tools/runtime-verify.js
```
